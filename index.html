3. すべての本アプリに共通する方針

  • 会員登録やログインは不要です。運営者が、氏名・メールアドレス・電話番号・住所などの個人情報の入力を求めたり、取得したりすることはありません（ニチカレで利用者が任意に Google アカウントでバックアップ機能を使う場合を除きます。第4項を参照）。
  • 利用者が本アプリで作成した情報（メモ、予定、家計の記録、写真に付けた感想、ゲームの記録、設定など）は、利用者の端末の中にのみ保存されます。運営者のサーバーへ送信されることはなく、運営者がその内容を見ることはできません。
  • 運営者は、利用者の情報を販売したり、本ポリシーに記載した目的以外に利用したりすることはありません。
  • 本アプリをアンインストールすると、端末に保存された情報は削除されます。

4. アプリごとの情報の取り扱い

トコまるダッシュ

  • スコア、集めたクリスタルの数、購入したスキンやアイテム、設定などのゲームの記録は端末内にのみ保存します。ゲーム内の「クリスタル」は現実のお金では購入できません（アプリ内課金はありません）。
  • 本アプリは子どもを含む幅広い年齢の方を対象としているため、広告（Google AdMob）を子ども向けの取り扱いに設定しています。興味・関心に基づく広告（パーソナライズ広告）は表示せず、表示する広告は全年齢向け（G）のものに限定しています。
  • ゲームエンジン「Unity」により、端末の機種・OS・画面サイズなどの匿名の技術情報が Unity Technologies に送信される場合があります（第5項）。

ジャンメモ - 付箋みたいに使えるメモ帳ウィジェット

  • 作成したメモ、ゴミ箱に入れたメモ、リストの並び順などは端末内にのみ保存します。
  • ホーム画面ウィジェットに表示する内容も端末内の情報だけを使います。
  • 広告（Google AdMob）を表示します。また、Google Play の機能を使ってアプリの評価をお願いする画面を表示することがあります。

ニチカレ -日常カレンダー-

  • 登録した予定と、予定に付けた URL は端末内にのみ保存します。
  • 祝日の表示のため、インターネット上で公開されている祝日の情報を取得します。このとき、利用者の予定などの情報は送信しません。
  • Google ドライブへのバックアップ・復元（任意）：利用者がこの機能を使う場合に限り、Google アカウントでのログインを求め、利用者自身の Google ドライブに予定のバックアップを保存し、そこから読み込みます。バックアップは利用者自身の Google ドライブに保存され、運営者が受け取ったり、閲覧したりすることはありません。Google から取得した情報は、バックアップと復元の目的にのみ使用し、第三者に提供することはありません。
  • 予定に添付するファイルを選ぶ際は、利用者が選んだファイルにのみアクセスします。
  • 広告（Google AdMob）を表示します。

カメメモリー - 写真を地図で振り返る思い出記録 -

  • 端末内の写真と、写真に記録された撮影日時・撮影場所（位置情報）を読み取り、日付や場所ごとに整理して地図上に表示します。写真そのもの、および写真の位置情報を運営者のサーバーや第三者に送信することはありません。
  • 写真に付けたメモ・感想・評価・カテゴリ・リンクなどは端末内にのみ保存します。
  • 地図上で現在地を表示するために、端末の位置情報を使用します（許可した場合のみ）。現在地の情報は端末内で使用し、運営者に送信することはありません。
  • 地図の表示には Google マップを使用しています。地図を表示する際、表示している範囲などの情報が Google に送信されます。
  • 撮影場所の住所を表示するため、写真の撮影地点の緯度経度を、Android の住所変換機能（Google のサービス）を通じて住所に変換することがあります。
  • 写真に関連リンクを追加した場合、そのページのタイトルを表示するために、そのページにアクセスします。
  • 広告（Google AdMob）を表示します。

ワケマネ -分けて貯めよう簡単家計管理-

  • 予算、カテゴリー、支出の記録などの家計のデータは端末内にのみ保存します。
  • 広告（Google AdMob）を表示します。

爆音ブースター -広告一切無しで音量をブースト!!-

  • 端末で再生される音の音量を大きくする機能のみを提供します。録音や、再生中の音声の内容の取得は行いません。
  • 保存したプリセット（音量設定）と、チュートリアルの表示状況は端末内にのみ保存します。
  • ブースト中は、機能を継続するため通知を表示します。
  • 広告は表示しません。利用者の情報を外部に送信することはありません。

5. 利用している外部サービス

Google AdMob（広告配信）

広告を表示する本アプリ（第2項の「広告：あり」のアプリ）は、Google LLC の広告配信サービス「Google AdMob」を利用しています。広告の配信、表示回数の管理、効果測定、不正防止のために、Google AdMob により次の情報が収集・利用される場合があります。

  • IP アドレス、およびそこから推定されるおおよその地域
  • 広告 ID などの端末の識別子
  • 端末の機種、OS のバージョン、言語などの端末情報
  • 広告の表示やタップの状況、アプリの動作に関する診断情報

興味・関心に基づく広告の表示を望まない場合は、端末の「設定」から広告 ID を削除する、またはパーソナライズ広告を無効にすることができます。なお、トコまるダッシュでは、設定にかかわらずパーソナライズ広告を表示しません。

  • Google プライバシーポリシー：https://policies.google.com/privacy
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用：https://policies.google.com/technologies/partner-sites

Google マップ（カメメモリー）

  • Google マップ／Google Earth 追加利用規約：https://maps.google.com/help/terms_maps/
  • Google プライバシーポリシー：https://policies.google.com/privacy

Google ドライブ・Google ログイン（ニチカレ）

ニチカレのバックアップ機能では、Google の認証とドライブの API を利用します。Google のユーザーデータの取り扱いは、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

  • Google API サービスのユーザーデータに関するポリシー：https://developers.google.com/terms/api-services-user-data-policy

Unity（トコまるダッシュ）

  • Unity プライバシーポリシー：https://unity.com/legal/privacy-policy

6. お子さまの利用について

「トコまるダッシュ」と「爆音ブースター」は、お子さまを含む幅広い年齢の方を対象としています。運営者がお子さまから個人情報を取得することはありません。トコまるダッシュの広告は第4項のとおり子ども向けの取り扱いで配信し、爆音ブースターには広告がありません。保護者の方で、本アプリの情報の取り扱いについてご不明な点がある場合は、第9項のお問い合わせ先までご連絡ください。

7. 第三者への提供

運営者は、第5項に記載した外部サービスによる取り扱いを除き、利用者の情報を第三者に提供することはありません。

8. 情報の削除

  • 端末内に保存された情報は、本アプリのデータの消去、またはアンインストールにより削除されます。
  • ニチカレで Google ドライブに保存したバックアップは、利用者自身の Google ドライブから削除できます。また、Google アカウントの設定からニチカレのアクセス権を解除できます。
  • 外部サービスが収集した情報の削除については、各サービスのプライバシーポリシーをご確認ください。
