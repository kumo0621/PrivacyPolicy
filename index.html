プライバシーポリシー

くもん（以下「当方」といいます）は、当方が Google Play で提供するすべてのアプリおよびサービス（以下「本アプリ」といいます）における、利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

第1条（取得する情報）

本アプリは会員登録を必要とせず、当方が利用者の氏名、メールアドレス、電話番号、住所などの個人情報を取得することはありません。本アプリでは、次の情報を取り扱います。

  1. 利用者が本アプリに入力した情報（メモ、予定、家計の記録、ゲームの記録、設定など）
  2. 端末内の写真および写真に記録された撮影日時・撮影場所、端末の位置情報（写真や地図を扱う機能で、利用者が許可した場合に限ります）
  3. Google アカウントの情報（Google ドライブへのバックアップ機能を、利用者が利用する場合に限ります）
  4. 広告 ID、IP アドレス、端末の機種や OS などの端末情報、アプリの利用状況（第4条の広告配信などのため、自動的に送信されます）

前項第1号から第3号の情報は利用者の端末内、または利用者自身の Google ドライブにのみ保存され、当方のサーバーに送信されることはありません。

第2条（利用目的）

当方は、取得した情報を次の目的で利用します。

  1. 本アプリの機能を提供するため
  2. 本アプリに広告を表示するため
  3. 本アプリの不具合への対応や改善のため
  4. 利用者からのお問い合わせに対応するため

第3条（第三者提供）

当方は、次の場合を除き、利用者の情報を第三者に提供しません。

  1. 利用者の同意がある場合
  2. 法令に基づく場合
  3. 第4条に定める外部サービスを利用する場合

第4条（広告および外部サービスの利用）

広告を表示する本アプリでは、Google LLC が提供する広告配信サービス「Google AdMob」を利用しています。Google AdMob は、広告の配信や効果測定のために、広告 ID などの情報を利用することがあります。詳しくは、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用をご確認ください。利用者は、端末の設定から広告 ID をリセットしたり、パーソナライズ広告を無効にしたりできます。

また、本アプリでは、機能の提供のために次の外部サービスを利用しています。

  • Google マップ（地図の表示）：Google プライバシーポリシー
  • Google ドライブ（バックアップ）：Google API サービスのユーザーデータに関するポリシー
  • Unity（ゲームの動作）：Unity プライバシーポリシー

第5条（子どものプライバシー）

当方は、子どもから個人情報を取得しません。子どもを対象に含む本アプリで広告を表示する場合は、すべての利用者に対して子ども向けの設定で広告を配信し、パーソナライズ広告を表示せず、全年齢向けの広告のみを表示します。

第6条（情報の削除）

本アプリの情報は、アプリのデータを消去するか、アプリをアンインストールすることで削除できます。Google ドライブに保存したバックアップは、利用者自身の Google ドライブから削除できます。

第7条（プライバシーポリシーの変更）

当方は、必要に応じて本ポリシーを変更することがあります。変更後の本ポリシーは、本ページに掲載したときから効力を生じるものとします。
